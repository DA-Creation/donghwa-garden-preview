- 실행: index.html 또는 정기구독_A.html
- 주요 순서: 히어로 → 모집 띠 → 집에서도 제대로 묵어야지 → 분홍 CTA → 식단 소개 → 기수 안내 → 세 가지 고집 → 강릉 본점의 온기 그대로
- 첫 고집: 순두부로 단백질도 / 할미가 챙겨줄게.
- 둘째 고집: 우리 아기 바쁘니까, / 밥은 할미가 해 줄게.
- 셋째 고집: 할미가 키우고 장보고 / 직접 만든다.
