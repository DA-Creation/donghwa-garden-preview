# 동화가든 · 나에게 맞는 정기배송 식단 찾기

기존 GitHub meal-quiz의 화면·서체·에셋·모바일 하단 메뉴를 이어받아, 생활 리포트를 정기배송 고정 구성 추천으로 바꾼 로컬 시안입니다. 운영 사이트와 원본 보관 폴더는 수정하지 않았습니다.

## 실행

Node.js에서 `node server.mjs`를 실행한 뒤 http://127.0.0.1:8781/ 로 접속합니다.
검증은 `node --test model.test.mjs`로 실행합니다.

## 구현 범위

- 4단계: 함께 먹는 인원과 집밥 횟수 → 밥상 구성 → 좋아하거나 자주 먹는 음식(최대 3개) → 피하는 음식
- 정해진 상품 중 1순위와 대안 2개 추천, 전체 10개 구성 열람
- 구성 상세, 상품가/배송비/결제금액, 단품 합산가 대비 상품가 차이
- 답변 변경, 다시 시작, 이전 단계, 브라우저 뒤로 가기, 탭 내 새로고침 복원
- 원재료나 맵기를 바꾸는 기능 없음. 신청 버튼은 기존 Café24 신청 안내로 이동하며 상품을 자동 주문하지 않음.

## 상품 데이터의 출처와 범위

사용자가 제공한 2026-08-15 「강릉동화가든 신규 사업 반찬 정기배송 구독 마케팅 실행 계획서」 PDF 6–7쪽의 상세 10개 옵션을 사용했습니다.

- PDF는 제안 자료입니다. UI 가격 가까이에 구성안 기준임을 표시했습니다.
- 앞쪽 요약의 이전 가격보다 6–7쪽 상세표를 사용했습니다. 확정된 실판매 가격이라는 뜻은 아닙니다.
- 4개 주력 출시안 외에도 상세표에 있는 10개 옵션을 이번 시안에서는 탐색할 수 있습니다.
- 강릉 이웃 위클리는 지역 확인 전 자동 추천에서 제외하고, 전체 구성의 지역 전용 영역에 표시합니다. 미확인 배송비와 단품 합산가의 +α는 추정하지 않습니다.
- 국물 위크에 일반 순두부를 추가하지 않았습니다. 상세표에 적힌 얼큰순두부·비지찌개·우거지국·강된장볼·김치만 표시합니다.
- 발효 건강의 '저염' 표현은 검증된 영양 수치가 없어 화면의 우월성 주장으로 사용하지 않았습니다.
- 상차림 사진은 원본 에셋이며 실제 구독 상자의 포장·전체 구성 사진을 뜻하지 않도록 '상차림 예시'로 표시합니다.

## 추천 규칙

추천 규칙은 이번 시안의 기획 가정이며, 검증된 고객 분류나 운영사의 확정 기준이 아닙니다.

1. 지역 및 명시된 기피 음식 조건으로 후보를 제한합니다.
2. 인원에 맞는 기본 옵션을 우선합니다. 혼자/불규칙은 솔로, 둘은 풀 베이직, 셋 이상은 패밀리에 가중치를 줍니다.
3. 국 중심/반찬 중심 식사, 얼큰한 음식/청국장 등 기호를 반영합니다.
4. 답변을 근거로 추천 이유를 문장으로 보여줍니다. 허구의 적합도 백분율이나 건강 점수는 만들지 않습니다.

기피 음식은 구성표에서 확인되는 것만 제외합니다. 회차별 반찬 원재료를 전부 알 수 없으므로 알레르기 안전을 보장하지 않습니다. 두부·콩 음식은 전 옵션에 들어 있어, 이 항목을 피하면 무리한 추천 대신 일치하는 구성이 없다고 보여줍니다.

## 가격·영양 비교

동일 구성의 PDF 단품 합산가와 구독 상품가만 비교합니다. 배송비는 별도 표시합니다. 단품 배송비가 없으므로 총 결제금액 대비 할인이라고 표시하지 않습니다.

PDF에는 구독 상자의 총 끼니 수와 영양 성분이 없습니다. 국 620g의 2인분 표기를 전체 상자의 끼니 수로 확장하지 않았고, 집밥 횟수를 실제 구독 섭취량이나 외식 대체량으로 취급하지 않았습니다. 따라서 외식 대비 절약액·단백질·나트륨 차이는 만들지 않았습니다.

결과에서는 평소 음식과 추천 음식의 구성 차이를 보여줍니다. 동일한 1인 한 끼 기준, 확인된 수치와 출처가 갖춰진 경우에만 정량 비교하도록 model.mjs의 검증 함수를 분리했습니다. 현재 제품 데이터에는 영양 수치를 넣지 않았습니다.

## 검증 기록 · 2026-09-19

- Node 테스트 15개 통과: 인원·밥상·기호별 추천, 기피 음식 우선 제외, 추천 없음, 지역 옵션 제한, 배송비·상품가 비교, 응답 정리, 영양 비교 데이터 검증.
- 브라우저에서 4단계 전체 진행 → 얼큰 한상 / 프리미엄 패밀리 결과를 확인했습니다.
- 음식 3개 초과 선택 제한, 없음의 상호배제, 답변 수정 후 추천 없음, 새로고침 복원, 브라우저 뒤로 가기를 확인했습니다.
- 전체 10개 구성과 강릉 전용 상세, 모달 간 이동 시 초점, Escape 닫기, 다시 시작을 확인했습니다.
- 320px·390px 모바일과 기본 데스크톱 화면을 확인했습니다. 가로 넘침과 깨진 이미지가 없고, 브라우저 오류·경고 로그가 없었습니다.
- 실제 주문 및 결제는 수행하지 않았습니다.
