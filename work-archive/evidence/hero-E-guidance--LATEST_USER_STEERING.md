# 최신 사용자 수정사항 — 상품 42 히어로

기록일: 2026-10-29

이 문서는 현재 대화에서 전달된 최신 수정사항의 **실행용 요약**이며 사용자 발언의 직접 인용문은 아니다. 기존 문서와 충돌하면 이 수정사항을 우선한다. 상세 근거와 검토한 파일 목록은 [기존 이미지 지침 감사](analysis/EXISTING_GUIDELINES_AUDIT.md)에 있다.

## 현재 요구

- 현재 영상은 가짜 김·연출된 국물방울·단일 클로즈업 위주의 단조로운 동작 때문에 원하는 결과가 아니다.
- 작업자가 새로운 액션이나 분위기를 더하지 않는다. 쿠캣 상품 1834 **상세본문 첫 영상**의 실제 3컷 구도·길이·수저 동작·작은 리프레이밍을 매우 가깝게 따른다. 상단 갤러리 영상과 혼동하지 않는다.
- 음식과 분량·그릇·색·표면 질감은 오직 동화가든 실제 상품 사진을 따른다. 쿠캣의 달걀·버섯·고기 등 다른 음식이나 분량을 복사하지 않는다.
- 원본 순두부는 크기가 다른 부드러운 찢김면·접힘·젖은 잔조각이 자연스럽게 이어진 형태다. 규칙적인 구슬·쌀알·사슬·콜리플라워 미세 돌기를 반복하거나 모든 작은 입자를 새로 선명하게 만들지 않는다. 실제 잔조각 자체를 없애거나 매끈한 큐브·공·퓨레로 바꾸지도 않는다.
- 김·연무·방울·액체 실·낙하·기포·거품·끓음·튀김·동심원 파문을 새로 만들지 않는다. 불에서 내린 음식의 표면은 수저가 닿는 곳만 움직인다. 원본 사진의 증기와 쿠캣의 끓음은 생성하지 않는다.
- 이전 iCloud 이미지 제작 지침과 재검수를 읽고 반영한다. 과거의 일부 `pass` 판정이나 ‘작고 자연스러운 방울’이라는 표현을 현재 허용 근거로 삼지 않는다.

## 현재 요구한 장면과 참조 역할

- `reference/donghwa-42-actual-product.jpg` — 실제 음식 정체성의 유일한 시각 근거.
- `reference/cookat-1834-detail-hero.mp4` — 구도·컷·동작·절제된 리프레이밍만의 참조. 현재는 해당 시작 프레임을 새 이미지 구도 참조로, 영상 자체를 로컬 비교 근거로 사용한다.
- 실제 쿠캣 컷 경계는 1.418083초와 4.045708초. 최종은 약 6초이며, 24fps 원본 확인 시 34+63+44프레임=141프레임/5.875초, 경계 1.416667/4.041667초로 편집한다. 6.000초를 강제로 맞추지 않는다.
- 첫 컷: 우상단 나무 스푼의 **기존 음식 중 소량의 불규칙한 순두부**를 국물에 닿게 내려놓고 빈 스푼을 뺀다. 달걀을 추가하거나 공중으로 떨어뜨리지 않는다.
- 둘째 컷: 같은 방향에서 약간 넓어진 구도. 우상단 금속 스푼으로 현재 내용물을 밀고 접듯 젓는다.
- 셋째 컷: 가까운 금속 스푼이 국물 표면에서 시작해 한 입을 들어 올린다. 쿠캣에서 관찰한 작은 위쪽 따라 움직임만 허용한다. 이미 공중에 있는 완성 스푼으로 시작하지 않는다.

사용자는 이번 참조의 매우 가까운 구도 재현을 요청했다. 따라서 과거에 작업자가 정한 ‘쿠캣 영상을 생성 입력으로 사용하지 않는다’는 제한은 V2의 영상 참조 시도에 적용하지 않았다. 이는 경쟁사 음식이나 영상을 완성 결과물로 복사·게시한다는 뜻이 아니다. 생성되는 결과는 동화가든 실제 음식이어야 한다.

## 실패를 반영한 현재 실행 경로와 기록

현재 활성 경로는 **새 시작 이미지 3개 검수 → 4초 I2V 3개 → 좋은 구간을 원속도로 선택해 직접 편집**하는 V3다. 아래 구현 변경은 V2의 제품 정체성 실패에 따른 대응이며, 사용자에게 승인받은 구도 재현 의도를 바꾸는 것이 아니다.

- 새 이미지 요청 기록: [v3-keyframe-prompts.json](prompts/v3-keyframe-prompts.json). 실제 제품 사진+해당 쿠캣 시작 프레임의 역할을 구분한다.
- 각 새 이미지를 먼저 실제 사진과 비교해 검수한다. 기존 D/V1의 규칙적 입자 이미지나 V2의 경쟁사 음식 이미지를 입력으로 쓰지 않는다.
- 다음 I2V에는 검수된 해당 이미지 하나만 넣고 경쟁사 영상은 넣지 않는다. 컷별 실제 프롬프트/파라미터/예측 ID/결과와 사용 구간은 ledger에 기록한다.
- V2는 [공개 기각](qa/attempt-002/DECISION.json). 동작 참조의 회색 냄비·노른자·긴 버섯이 남아 동화 음식으로 바뀌지 않았다. [V2 TXT](prompts/42-reference-motion-v2.txt)와 [V2 JSON](prompts/42-reference-motion-v2.json)은 실패 이력으로만 보존한다.
- 이전 V1: [공개 기각 결정](qa/attempt-001/DECISION.json). 규칙적 과선명 입자·레퍼런스와 다른 3동작·남은 김 때문에 공개 기각되었다. 그때의 생성 이미지 3장도 현재 승인 입력으로 쓰지 않는다.
- 변경 전 문서: [보존본 해시 목록](analysis/pre-user-correction/SOURCE_HASHES.json). 역사 기록이며 현재 실행 지침이 아니다.
- [활성 제작 지침](GENERATION_GUIDELINES.md), [활성 컷 계획](SHOT_PLAN.md), [활성 검수표](qa/ACCEPTANCE_CRITERIA.md).

이 수정사항 기록은 새 이미지나 V3 영상의 생성 성공·시각 합격·업로드·사용자 선택을 의미하지 않는다. 실제 상태는 시도별 증거에 따라 별도로 기록한다.
